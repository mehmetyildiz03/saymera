# SAYMERA Atlas Roadmap — v1.8.1

The Atlas is now a curriculum roadmap rather than a mastery-card grid for Primary 2.

## Rules

- Units preserve the canonical Singapore P2 sequence from the v1.8 learning architecture.
- The current unit opens automatically.
- Unit headers are expandable so the complete 22-lesson path is visible without becoming one long wall.
- Lesson state is one of: completed, current, locked, or available.
- “Completed” means the first learning cycle has completed. It is deliberately not the same as stable/mastery.
- Completed lessons remain selectable and can be revisited.
- Future new learning remains visible but locked. A tap explains which earlier lesson blocks it.
- A due delayed review appears as a separate “Tekrar hazır” badge; it does not revoke lesson completion.
- No mastery percentage is shown in the Primary 2 Atlas.

Until the dedicated Lesson Center lands in v1.8.2, selecting an unlocked lesson launches a targeted session for that lesson. Targeted launches suppress unrelated global review prepending so the selected lesson is actually the one that opens.
