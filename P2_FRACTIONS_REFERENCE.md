# Singapore P2 Fractions — SAYMERA v1.4.2

Resmî Singapore MOE Primary 2 kapsamına göre kesir katmanı dört ayrı beceriye bölünür:

1. Fraction as part of a whole → `fractionMeaning2`
2. Notation and representations of fractions → `fractionNotation2`
3. Comparing and ordering unit/like fractions, denominators ≤ 12 → `fractionCompare2`
4. Adding/subtracting like fractions within one whole, denominators ≤ 12 → `fractionAddSub2`

Pedagojik invariant: kesir sembolü anlam kurulmadan sınanmaz. İlk beceri eş parça/bütün ilişkisini sembolik kesir yazımı varsaymadan kurar. İkinci becerinin temsil aşamasında `a/b` gösterimi açıkça öğretilir; daha sonraki sembol görevleri bunu ölçer.
