# Singapore P2 Geometry & Data — SAYMERA v1.5.1

Kaynak: Singapore MOE Primary Mathematics Syllabus P1–P6, current Primary Two scope.

## P2 geometry
- P1'de başlayan yarım/çeyrek daire, birleşik 2B figür ve ızgarada kopyalama deneyimleri P2'de de daha geniş sınıflandırma/oluşturma bağlamında kullanılır.
- make/complete 2D shape patterns using one or two attributes: size, shape, colour, orientation
- identify, name, describe and classify: cube, cuboid, cone, cylinder, sphere
- make/complete patterns with 3D shapes (except sphere) using one or two attributes

## P2 statistics
- read and interpret picture graphs with scales
- solve one-step questions from the graph

## SAYMERA reference skills
- `shapes2D2` — birleşik 2B figür ve gerçek kareli-alan kopyalama
- `shapePatterns2` — 2B örüntüler
- `solids2` — 3B cisimleri tanıma/sınıflandırma
- `solidPatterns2` — 3B cisim örüntüleri; sphere örüntü havuzuna alınmaz
- `pictureGraphScale2` — ölçekli resimli grafik

Tüm beceriler readiness → model → representation → symbol → reasoning → context → adaptive practice → delayed retrieval döngüsünü kullanır. Çocuk ekranı bu motor adlarını açıklamaz.
